## 0. 总原则

### 0.1 品牌识别（允许 / 禁止）

| 允许 | 禁止 |
|------|------|
| 抽象几何徽记、首字母组合、物业中英文简称（仿真） | 完整官方 Logo 矢量盗用、受保护吉祥物一比一 |
| 公开可感知的主色气质（金沙冷欧式、永利暖金等） | 声称「官方正版场景」 |
| 每家独立桌布纹样、牌背、筹码环纹 | 六家共用同一贴图只改色相 |
| 界面角标：「XX 仿真训练主题」 | 仿冒博彩牌照或支付品牌 |

### 0.2 资产独立性硬性要求

每一家赌场必须具备**成套独特资产**，禁止「换皮 RGB」：

1. **牌桌**：围边材质 + 呢面底色 + 注区线稿纹样 + 限红牌造型  
2. **扑克**：牌背主图案 + 角花 + 牌面字标风格（仍保持可读）  
3. **筹码**：环带配色算法 + 边缘齿纹/嵌条 + 中心章  
4. **计分器/路单**：珠盘与大路的框体、字体、指示灯风格  
5. **显示器**：边框、支架、UI 铬色、开机/待机装饰条  
6. **荷官（风格预留）**：制服主色、领饰、手套、名牌版式（本批出色板与剪影，模型 Phase 后）

## 3. 共用几何（可一致）vs 必须独特（不可一致）

| 项目 | 六家可否相同 |
|------|----------------|
| 半椭圆桌比例、7 座角度、牌锚点逻辑 | **可相同**（骨架） |
| 闲蓝/庄红/和绿的**功能语义色** | **可相近**（可访问性） |
| 呢面底色、围边、纹样、限红牌造型 | **必须不同** |
| 牌背主图案 | **必须不同** |
| 筹码环带与中心章 | **必须不同** |
| 路单外框与字体气质 | **必须不同** |
| 显示器边框与待机动画 | **必须不同** |
| 荷官制服方案 | **必须不同** |

## 4. 筹码面额与环带（各主题在同面额上仍要有家族纹样）

建议统一面额：100, 500, 1000, 5000, 10000, 25000（训练币）。  
**同一面额六家主环色可参考行业习惯，但中心章、齿纹、副环必须按上表家族区分。**

每枚筹码必须有微标：TRAIN 或中文「訓」。

## 5. 计分器（路单）功能布局（六家结构同、皮肤不同）

标准模块（每家都要）：

1. **珠盘 Bead Road**  
2. **大路 Big Road**  
3. **大眼仔 / 小路 / 曱甴路**（可折叠，手机默认收）  
4. **当前靴统计**：庄/闲/和/对 次数  
5. **桌信息条**：桌号、限红、标准|免佣  

皮肤只改：外框、标题字体、格子线、指示灯、是否显示品牌抽象徽。
