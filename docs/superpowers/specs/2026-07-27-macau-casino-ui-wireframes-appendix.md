## D. 桌型视觉差异速查（设计用）

| 桌型标签 | 桌布/标识 | 注区 | 设备 |
|----------|-----------|------|------|
| 标准大众 | 绿/蓝呢 + 佣金提示 | P/B/T + 可选对子 | 传统或智能 |
| 免佣 | 免佣大字 | 庄注区旁赔付说明 | 同左 |
| 咪牌 | 同标准 | 同 + 咪牌流程 UI | 盖牌 mesh |
| 贵宾少座 | 暗金呢、3–5 座 | 简化边注 | 更高私密环境 |
| 智能桌 | 电子注区描边 | 同逻辑 | 桌面屏 |
