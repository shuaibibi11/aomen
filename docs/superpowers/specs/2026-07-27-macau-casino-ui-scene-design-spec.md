## 0. 重要声明（真实模拟边界）

### 0.1 我们承诺的「真实」

| 层级 | 含义 | 本系统做法 |
|------|------|------------|
| **规则真实** | 补牌、赔付、免佣、边注、桌务流程 | 引擎 + Rule Pack 权威实现 |
| **流程真实** | 兑码→上桌→下注→停注→发牌→咪/开→结算→换靴→离桌 | 状态机 + 教学模式/真实模式 |
| **空间真实** | 桌型几何、座位、注码区、荷官位、靴/牌靴、托盘 | 统一桌几何 + 赌场皮肤包 |
| **氛围真实** | 灯光、材质、制服色、厅区层级（大众/中场/贵宾） | 场景 Profile + 品牌主题 token |
| **运营真实** | 限红牌、路单、智能桌设备外观 | UI 组件 + 可配置开关 |

### 0.2 我们不承诺的「像素级克隆」

- **不复制**各赌场受版权保护的完整商标图形、吉祥物、受保护装潢一比一抄袭。
- **采用「可识别仿真」**：色彩气质、厅区层级、桌布主色、限红与桌务差异用 **Casino Theme Pack + 公开可核验参数** 表达；对外可标注「训练仿真，非官方授权」。
- **限红、厅名、桌数会随时间变化**；规范要求所有数值来自 **Rule Pack 版本化数据**，禁止写死在美术材质里。

### 0.3 调研方法与资料分级

| 等级 | 来源 | 用途 |
|------|------|------|
| A | 官方物业介绍、公开新闻（智能桌部署等） | 物业定位、设备趋势 |
| B | 行业指南、游记/桌台攻略（限红区间、客群） | 默认限红带、厅区分层 |
| C | 通用百家乐国际桌标准（座位、注区逻辑） | 桌几何与交互热点 |
| D | 待机构现场采证 / 授权素材 / 教练校准 | 最终上线「该厅该桌」验收 |

**本 v0.1 以 A+B+C 建立可开发基线；D 级采证清单见文末。**

## 1. 澳门赌场调研摘要（设计输入）

### 1.1 六大持牌与代表物业（训练系统必覆盖品牌轴）

| 集团 | 代表物业（示例） | 设计气质关键词（训练用，非官方 slogan） | 厅区分层建议 |
|------|------------------|------------------------------------------|--------------|
| 金沙中国 Sands | 威尼斯人 Venetian、巴黎人、金沙 | 大型综合、运河/欧式装饰、桌量极大、人流密 | 大众大厅 / 中场 / 贵宾 |
| 银河 Galaxy | 澳门银河、百老汇 | 现代综合度假、明亮宽敞、家庭友好与博彩并存 | 大众 / Horizon 类中高场 / VIP |
| 永利 Wynn | 永利澳门、永利皇宫 | 奢华、暖金、精致灯光、表演水景联想 | 大众 / Diamond 类 / VIP 包厢感 |
| 新濠 Melco | 新濠天地、新濠影汇 | 潮流夜生活、年轻、舞台感、娱乐秀场 | 大众 / 特色主题厅 / VIP |
| 美高梅 MGM | 美高梅、美狮美高梅 | 艺术装置、当代、干净线条 | 大众 / 中场 / VIP |
| 澳博 SJM | 新葡京、上葡京等 | 半岛传统符号、经典赌场意象 | 大众 / 贵宾（历史感更强） |

> 公开报道指出：澳门多家已在**大众百家乐**大规模部署 **Smart Table（智能桌 / RFID 等）**（如银河、MGM、金沙、永利相关报道）。训练系统 3D 桌应支持 **「传统桌 / 智能桌」两种桌面设备外观开关**。

### 1.2 百家乐在澳门的产品现实（影响 UI）

1. **收入与桌台占比极高** → 训练首页与选桌应以百家乐为默认主路径。  
2. **大众 / 中场 / 贵宾** 限红与私密性差异巨大 → 选桌 UI 必须先选 **厅级**，再选桌。  
3. **公开资料中的限红量级（仅作默认区间，上线以 Rule Pack 为准）**  
   - 路氹大型综合：大众常见约 **HKD/MOP 300–1000+** 起（周末节假日会上调）  
   - 半岛部分传统场：可能有更低门槛桌（游记口径 100–300 档，需 D 级核验）  
   - 贵宾：可至极高封顶，训练用「可配置封顶」+ 脱敏展示  
4. **智能桌** → 桌面可有电子屏/下注感应区视觉；荷官流程仍走同一状态机。

### 1.3 标准百家乐「物理桌」设计事实（C 级，全球通用 + 亚洲常见）

| 元素 | 典型真实情况 | 本系统规范 |
|------|--------------|------------|
| 座位 | 常见 **7 个玩家位**（部分 5/6/9，贵宾可更少） | 默认 7；Rule Pack playerSeats |
| 桌形 | 半椭圆形，荷官在弦侧，玩家在弧侧 | 统一 mesh，仅换材质/贴花 |
| 主注区 | 每座前：**闲 Player / 庄 Banker**；中央或共享 **和 Tie** | 每座独立 P/B + 共享或分座 T |
| 边注 | 对子、完美对子、龙宝等，**因场而异** | 注区 mesh 可显隐 + 赔率牌 |
| 牌区 | 闲/庄两堆牌位在荷官前方 | 固定 bone 节点 card_player_* / card_banker_* |
| 靴 | 8 副常见；牌靴在荷官右手或左侧（因场） | shoeAnchor 可配置左右 |
| 码箱/托盘 | 荷官身前浮码、色筹 | chipTray 节点；训练币视觉 |
| 限红牌 | 桌角或灯箱：**Min–Max** | 3D 小牌 + HUD 同步 |
| 路单 | 旁侧电子或纸本大路/珠盘 | 2D HUD 为主，3D 可挂显示器 |
| 佣金 | 传统 5% 庄；免佣桌标识不同 | 桌头 variant 徽章 |

### 1.4 「赌场差异」在视觉上真正该长什么样

**不要**为每家赌场做完全不同的桌几何。  
**要**做三层差异：

`	ext
L1 品牌 Theme Token（色、灯、地毯、柱、logo 位）
L2 厅级 Spatial Profile（天花板高度、人声密度、私密度、智能桌开关）
L3 桌级 Table Template（限红、边注显隐、免佣、咪牌、座位数量、靴位置）
`

这与产品 Rule Pack 三级（Casino → Pit → Table）**一一对应**。

## 2. 设计原则与仿真等级

### 2.1 产品设计原则

1. **训练优先于观光**：信息可读、操作可达 > 电影运镜。  
2. **规则零折扣**：任何画质降级不得改变注区逻辑与结果。  
3. **双身份**：玩家/荷官两套主相机与主操作栏；教练第三套。  
4. **双端**：PC 精细；手机大热点 + 底部栏；iOS 可降到 2.5D 保底。  
5. **可配置真实**：所有「像哪家」来自 Theme/Rule Pack，不写死代码。  
6. **合规训练币**：筹码外观可仿色筹体系，界面永久 **训练币 / 非真实货币** 水印（可配置位置）。

### 2.2 视觉仿真等级（Visual Fidelity Tier）

| 等级 | 名称 | 使用场景 | 技术 |
|------|------|----------|------|
| **V0** | 线框/示意图 | 开发、无资源机 | 纯 2D SVG/Canvas 俯视 |
| **V1** | 高保真 2.5D | 手机弱机、教学强调注区 | 透视贴图桌 + 精灵筹码/牌 |
| **V2** | 实时 3D 标准 | PC 默认、手机中高 | R3F，中模，硬阴影或轻阴影 |
| **V3** | 实时 3D 高配 | PC 高配教室 | 更高模、PBR、环境反射（仍控预算） |

**同一局可在 V0–V3 切换，引擎 Snapshot 不变。**

### 2.3 视角规范（Camera Rigs）

| Rig ID | 名称 | FOV 建议 | 用途 |
|--------|------|----------|------|
| cam_player_seat_{n} | 玩家位 | 50–60° | 学员练玩家 |
| cam_dealer | 荷官位 | 45–55° 半俯 | 学员练荷官 |
| cam_god_orbit_presets | 上帝预设 | 35–45° | 教练讲解（手机仅预设） |
| cam_pit_overview | 厅区总览 | 宽 | 选桌前预览（可 2D） |

手机：**禁止**自由六自由度飞相机默认开启；仅 PC 教练可开「有限轨道」。

## 5. 赌桌 2.5D / 3D 场景设计规范

### 5.1 场景节点树（所有赌场共用骨架）

`	ext
TableRoot
├─ Environment（厅级：灯、雾、环境光、远处模糊人群可选）
├─ TableMesh
│   ├─ Felt（桌布材质 + 印刷 UV：注区线稿）
│   ├─ Rail（围边）
│   ├─ DealerInset（荷官凹位）
│   ├─ ChipTray
│   ├─ Shoe
│   ├─ DiscardRack
│   ├─ LimitPlaque
│   └─ Optional: SmartTableScreens
├─ Seats[1..N]
│   ├─ Chair
│   ├─ BetSpot_Player
│   ├─ BetSpot_Banker
│   ├─ BetSpot_Tie (or shared)
│   ├─ BetSpot_Side_* (optional)
│   └─ ChipAnchor
├─ CardAnchors（Player1,2,3 / Banker1,2,3）
├─ Characters（DealerLOD / PlayerLODs 可关）
└─ Cameras（rigs）
`

**热点 ID** 必须与 Intent 映射表一致，例如：hotspot.bet.seat3.player → place_bet。

### 5.2 桌布（Felt）印刷规范

1. **主色**：按 Theme（绿呢经典 / 蓝呢现代 / 深紫贵宾等），来自 Theme Pack。  
2. **文字**：中英双语或按 scriptPack：閒/PLAYER、莊/BANKER、和/TIE、對子等。  
3. **字体**：无衬线、高对比；避免过花纹导致手机不可读。  
4. **注区对比**：填充与描边 ΔE 足够；色盲模式提供纹理区分（点/线）。  
5. **免佣桌**：明显 NO COMMISSION / 免佣 桌头标识。  
6. **禁止**把 Min/Max 烤死在贴图；限红用 **动态纹理或 3D 牌** 显示 Rule Pack 数值。

### 5.3 灯光

| 厅级 | 环境光 | 主光 | 备注 |
|------|--------|------|------|
| 大众 | 偏亮中性 | 顶光均匀 | 人感嘈杂可用轻微环境音后期 |
| 中场 | 对比略强 | 暖一点 | |
| 贵宾 | 暗环境 + 桌面重点光 | 桌面高亮、周围压暗 | 私密感 |

V1 2.5D：预烘焙光照贴图即可。

### 5.4 牌与发牌动画

- 牌背：可主题化，但需统一可读。  
- 发牌顺序动画时长可配置；**权威以落地张数为准**，动画可跳切。  
- 自然 8/9：可加速进开牌。  
- 咪牌：仅 peekAllowed 桌启用特殊镜头与盖牌 mesh。

### 5.5 筹码

- 面额色：遵循 Theme chipset.colors（可接近行业习惯：如 100/500/1000 色带），**全部印「TRAIN」微标**。  
- 下注：从本座 ChipAnchor 弧线到 BetSpot。  
- 收付：先收输后付赢的顺序可配置（荷官训练评分点）。

### 5.6 智能桌外观（可选）

- 注区可有轻微电子边框/嵌入屏。  
- 不改变 Intent；仅 sceneProfile.smartTable=true。

### 5.7 性能预算（目标）

| 端 | V2 三角面（桌+人物简化） | 绘制调用 | 备注 |
|----|--------------------------|----------|------|
| PC | 建议桌主体 < 80k tris 量级可再调 | 尽量合并 | |
| iOS Safari | 强制 LOD1，人物可关 | 更严 | 自动降 V1 |

## 7. 设计系统（2D UI Token）

### 7.1 布局栅格

- PC：12 列，边距 24，沟 16；对局沉浸可破格。  
- 手机：边距 16；底栏安全区预留 home indicator。  

### 7.2 字体

- 中文：系统优先「苹方 / 微软雅黑」栈；关键数字等宽（限红、倒计时、筹码）。  
- 最小正文：PC 14 / 手机 15；注区标签跟随 3D 世界字号另测。  

### 7.3 色意（功能色，与品牌 token 分离）

| 语义 | 用途 |
|------|------|
| 闲 Player | 蓝系（可配置，保持全球常见认知） |
| 庄 Banker | 红系 |
| 和 Tie | 绿系 |
| 成功/派彩 | 亮绿反馈 |
| 警告/停注 | 琥珀 |
| 错误/违规 | 红 |
| 教学 | 信息蓝紫，不与庄红冲突 |

### 7.4 组件库（需出组件稿）

- CasinoCard、PitChip、TableRow、LimitBadge、ModeBadge  
- ChipDenomination、BetSlipSummary  
- PhaseTimer、SubtitleBar、TeachStepper  
- SeatMap2D、CoachTimeline、ScoreRadar  
- Button 主/次/危险；Drawer 手机菜单  

### 7.5 动效

- 教学高亮：呼吸边框 1.2s，可关。  
- 筹码飞入：200–400ms。  
- 不闪烁癫痫风险：禁止 <3Hz 强闪。

## 9. 与「真实澳门」对齐的验收标准（设计侧）

### 9.1 桌面真实感验收（每桌型）

- [ ] 7 座（或包规定座）位置与弧桌关系正确  
- [ ] 闲/庄/和/边注热区与 Rule Pack 开关一致  
- [ ] 限红显示与包数值一致且非烤死贴图  
- [ ] 标准 vs 免佣桌头标识可区分  
- [ ] 发牌落点、补牌出现在正确锚点  
- [ ] 荷官位可见靴与托盘  
- [ ] 智能桌开关仅外观  

### 9.2 赌场可识别验收（每 Theme）

- [ ] 选桌卡片 3 秒内能区分品牌气质（内部评审）  
- [ ] 进入桌后 Breadcrumb 与 Theme 一致  
- [ ] 无未授权商标完整复制（法务可过）  
- [ ] 训练水印可见  

### 9.3 训练可用性验收

- [ ] L1 热点可完成首局不看文档  
- [ ] 荷官轨道操作栏步骤与状态机一致  
- [ ] 手机一局不因点击热区过小失败  
- [ ] V1/V2 切换不丢注、不错结算
